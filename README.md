# 姿态索引 · Pose Index

中文姿势、服装与人像参考图库，带角色合成工作台和可选 ComfyUI 节点。姿势白模支持整库离线浏览，新增参考图按需从来源站点加载。

**[打开在线演示](https://1581610.github.io/ai-pose-gallery-offline-zh/)** · [原作者网站](https://ai-pose-gallery.pages.dev/) · [项目结构](docs/architecture.md)

- **素材原作者：** [ギア（@giaaibusi）](https://x.com/giaaibusi)
- **中文整理与工具维护：** [1581610](https://github.com/1581610)

姿势白模为 288 个姿势、1,439 张本地原图及对应缩略图，包含成人向艺术参考分类。
扩展目录收录 3,224 套服装、1,499 条人像参考，并为 1,439 张姿势图提供对应深度图入口。
中文扩展元数据整理参考 [Anhao 的 AI 角色参考与合成工作台](https://github.com/anhao/ai-pose-gallery-zh)。各来源和素材使用范围见 [NOTICES.md](NOTICES.md)。

## 开始使用

**在线浏览**

打开上方演示链接。姿势白模由本站静态文件提供，服装、人像和深度图按需访问各来源站点。

**离线浏览**

下载仓库 ZIP 并完整解压，双击根目录的 **`index.html`** 或 **`打开图库.cmd`**。
姿势白模原图、检索、收藏、备注与四图参考台可在断网时使用。扩展目录的检索数据随页面保存，其图片需要联网。
首次下载约数百 MB，解压后浏览不需要安装 Python、Node 或其他依赖。

一键入口在已有 Python 时启动仅监听 `127.0.0.1` 的本地服务；否则直接打开 HTML。
程序不会修改 PATH、Python、系统网络配置，也不会停止其他程序。

## 姿势浏览与个人资料

- 搜索中文、日文、编号和分类，支持空格分隔的多关键词与一组常用动作同义词。
- 按姿势、单图、五视角对照三种模式；缺失视角保留空位，避免错列。
- 主图和缩略图完整显示；大图适应窗口，支持滚轮／双指缩放、拖动与镜像。
- 原图加载完成后，未放大时可直接原生拖出；放大后拖动平移，按住 `Alt` 拖动可导出原图。
- 分别收藏整个姿势或某张图；创建参考集合，批量加入、移出、重命名。
- 为姿势写备注，返回最近浏览；四图参考台并排对照。
- 导出／合并导入个人资料 JSON，迁移收藏、集合、备注与参考台；兼容同一浏览器入口中的旧版 `pose_fav` 收藏。
- 导出筛选结果或所选图片的 CSV；复制实际图片路径。
- 分批生成卡片，记忆主题、卡片尺寸、筛选、视图和滚动位置。
- 浅深色主题、手机折叠筛选、键盘导航。无运行时框架、CDN、外部字体或统计脚本。
- 每组姿势带详细英文动作提示词，可选择附加当前视角前缀后复制。

| 操作 | 快捷键 |
| --- | --- |
| 聚焦搜索 | `/` |
| 换视角 | `←` / `→` |
| 换姿势，尽量保留视角 | `↑` / `↓` |
| 适应窗口／原尺寸 | `空格` |
| 收藏整个姿势 | `F` |
| 关闭大图 | `Esc` |

卡片右上角勾选用于批量操作：按姿势与对照模式选择此组内命中当前筛选的图片，单图模式选单图。
五视角模式展示命中姿势的完整角度上下文，必要时单独注明实际对照张数。
镜像仅改变显示，保留原文件。手机可在右上角帮助中导入／导出个人资料。
拖出操作携带原尺寸图片的地址与下载信息，供支持图片拖放的目标程序接收；也可使用“保存原图”。
图片拖出交给浏览器原生处理，不额外预读、缓存或要求选择本机目录。
在线版与本地服务版已验证：网页接收区收到与原图字节一致的 900×1200 PNG 文件。
直接双击 HTML 时，部分接收区可能只收到图片地址；可用 `打开图库.cmd` 启动离线本地服务，
或保存原图后再上传。具体接收方式由目标浏览器或软件决定。

整组收藏与单图收藏是独立开关：收藏姿势会使其所有视角出现在“我的收藏”，
但不会自动点亮每张图的单图收藏按钮。卡片会标明来自整组或单图的收藏关系。
支持最多 1000 个参考集合，导入超过限制会明确拒绝，不截断原资料。

**个人记录保存位置：** 浏览器本地存储。在线地址、本地 HTTP、直接打开的文件可能各自保存一份。
换入口、换电脑、搬文件夹或清理浏览器前，请先导出个人资料，再到新入口导入。

## 服装、人像与深度图

通过导航中的“服装库”和“人像库”浏览扩展目录，搜索中文名称、英文标签和编号。

## 角色合成工作台

1. 在图库中选定人像、服装和姿势，点击“加入配方”，也可添加自己的参考图片。
2. 打开导航中的“合成台”，选择白模或深度姿势参考，再选择画风并填写补充要求。
3. 复制组合提示词，或导出 `1800 × 1200` PNG 参考拼图。
4. 如需直接生成，打开“接口配置”，选择协议、端点和模型，填写本次会话的 API key，再回到合成台提交。

工作台提供 12 种画风选择。中文结构化提示词会组合已选素材描述，并保留姿势库中详细的英文动作提示词。
各核心槽位可随机选图或上传图片，附加参考支持文件选择、拖入、剪贴板粘贴与 HTTP/HTTPS 图片网址。
每张上传图片最多 20 MB，附加参考最多 16 张。配方支持独立的 JSON 导入与导出。
参考拼图包含已选的核心槽位，附加图片随生成请求另行传入。
最近 30 次生成记录保存在当前浏览器的 IndexedDB，可查看结果、复用配方和提示词或删除记录。
页面会尝试将远程生成结果保存为本地图片数据，读取受限时保留服务返回的图片网址，其有效期由服务方决定。
清理网站数据会同时清理这些记录，请及时下载需要保留的图片。

### 接口连接

| 协议 | 用途 |
| --- | --- |
| Google Gemini | 多图参考与图像生成 |
| OpenAI Images | 图像生成与参考图编辑 |
| 阿里云百炼 Qwen | 多模态图像生成与编辑 |
| 火山方舟 Doubao | 图像生成与多图参考 |
| ComfyUI | 导入 API 格式工作流、上传参考图、排队并读取输出 |

模型可用性、参数和费用以所选服务为准。API key 仅保存在当前页面内存，刷新或关闭页面后需要重新填写。
提交生成时，提示词和所选参考图会发送到用户配置的端点。生成服务应支持所选协议，并允许网页来源跨域访问。

GitHub Pages 提供静态页面，接口请求由浏览器直连。自定义 API 端点需要正确的 CORS 响应。
HTTPS 页面连接 HTTP 服务还可能受到混合内容和浏览器本地网络权限限制。
连接本机 ComfyUI 时，建议通过 `打开图库.cmd` 的本地 HTTP 入口使用，并按 ComfyUI 的配置方式允许这个具体来源。
导入工作流时使用 ComfyUI 导出的 API 格式 JSON，普通画布工作流需先转换为 API 格式。
导出的通用模板需要将 `YOUR_MODEL.safetensors` 替换为本机可用的 checkpoint，并按自己的工作流配置节点。
自定义工作流可使用 `{{prompt}}`、`{{seed}}`、`{{width}}`、`{{height}}`、`{{composite_image}}`、
`{{portrait_image}}`、`{{costume_image}}`、`{{pose_image}}` 和 `{{extra_image_1}}` 等占位符接入参考。
默认保留导入 API 工作流中的节点数值与连线。关闭“用界面尺寸与种子覆盖工作流”时，
工作流自身的尺寸和种子继续生效；打开后才使用合成台界面的尺寸与种子替换对应占位值。
如果提交状态未知，页面会提示服务可能已经接收任务，确认服务端状态后再重试，避免重复排队。
停止等待会结束页面轮询，ComfyUI 队列中的任务仍由 ComfyUI 管理。
有已保存的 ComfyUI 任务 ID 时，可继续追踪已有任务，恢复操作读取其状态和输出。

直接双击 `index.html` 时，浏览器可能限制本地图片读取、Canvas 导出或 API 请求。
本地 HTTP 入口可减少 `file://` 的限制。远程图片参与拼图或上传仍需要来源站点允许跨域读取，
如读取失败，可将有权使用的图片保存后手动上传为参考。

### 可选 ComfyUI 节点

仓库提供姿势、服装、人像和角色配方 4 个原生节点，可在 ComfyUI 画布中选图并输出图像与提示词。
将完整仓库放入自己的 `ComfyUI/custom_nodes/ai-pose-gallery-offline-zh/` 后重启 ComfyUI，
在右键菜单“姿态索引 / 参考图库”中添加节点，通过节点中的中文选图器填入图片。
三合一角色配方节点输出三张参考图、`1800 × 1200` 拼图与中英文提示词。
节点的 `safe_mode` 默认开启，`use_depth` 控制姿势深度图，`costume_view` 选择服装视角。
插件复用 ComfyUI 中的 `torch`、`numpy`、`Pillow` 和 `aiohttp`，扩展参考图仍按来源地址联网读取。
网页工作台可独立使用，安装节点由使用者在自己的 ComfyUI 环境中操作。

## 构建和维护

仅修改或重新构建时需要 Python 3.10+，普通下载、构建与发布工具只用标准库。

```powershell
# 修改 src/ 后生成可直接双击的离线入口
python -X utf8 scripts/build.py

# 生成在线页面，准备 GitHub Pages 发布目录 dist/
python -X utf8 scripts/build.py --hosted
python -X utf8 scripts/prepare_site.py

# 增量补齐缺失原素材；默认 8 并发，已有图片跳过
python -X utf8 scripts/download.py all --workers 8

# 重建中文 CSV / Markdown 索引
python -X utf8 scripts/build_index.py

# 从固定上游版本重建扩展元数据目录
python -X utf8 scripts/import_reference_catalog.py

# 离线校验扩展目录及来源 URL
python -X utf8 scripts/import_reference_catalog.py --check
```

姿势原始数据保留 `img/` 与 `thumbs/` 字段，脚本会自动映射到当前 `assets/` 目录。
下载器会重试失败请求，下载中断后可重跑。原站脚本访问受限时，也可通过
`--source-html 原站页面.html` 使用在浏览器保存的原作者页面引导元数据。

## 压缩和校验

压缩和逐图解码需要 Pillow；安装只需在自己的开发环境执行 `python -m pip install Pillow`。

```powershell
# 只在内存抽样测算，不创建、移动或删除图片
python -X utf8 scripts/optimize_images.py

# 写入较小且校验通过的 WebP，更新映射并重建，保留原图
python -X utf8 scripts/optimize_images.py --apply

# 重建成功后，显式将已切换引用的原图移至 .archive/originals/
python -X utf8 scripts/optimize_images.py --apply --archive-originals

# 检查全部引用、图片头、解码和尺寸
python -X utf8 scripts/verify.py --decode
```

默认转换为 RGB 像素无损 WebP；`--lossy`、`--gray` 会改变像素。
比原文件大的结果不切换引用。归档仍占磁盘空间，但可以恢复；程序不会自动清空归档。
构建遇到重复 ID、非法路径或缺图会明确失败，保留已有页面。
公开发布时使用完整姿势白模素材，若在本地归档过原图，先运行下载器从本机归档恢复或补齐。
此处的下载、压缩和逐图解码命令针对本地姿势白模资产。扩展参考目录保留来源 URL。

搜索、收藏、集合、备份、CSV、参考台、桌面／手机完整看图和压缩安全性。
只运行无需素材或浏览器的工具测试：`python -X utf8 tests/test_gallery.py --tools-only`。

组合操作与失败回退检查：


扩展目录、图像协议和可选节点的隔离检查入口如下。协议测试使用模拟响应，真实端点仍需在自己的环境中验证。

本轮未实现 ComfyUI `object_info` 动态节点参数表单，也未使用 WebSocket 节点进度推送。
当前高级参数通过 JSON 工作流和 HTTP 状态追踪配置，真实服务是否支持具体参数由服务端决定。

```powershell
python -X utf8 tests/test_reference_catalog.py
node tests/test_generator.cjs
python -X utf8 tests/test_comfy_plugin.py
python -X utf8 tests/test_workbench.py
```

多标签页会合并已保存的收藏增删；导入备份不会静默丢弃超限集合。

发布目录只包含编译页面与图片，不包含工具、测试、历史归档或个人记录。
