# 2026-10-28 复查记录

本轮检查覆盖组合交互、数据恢复、键盘与触控、构建失败回退、发布文件范围，以及来源和许可说明。
测试使用隔离浏览器与临时生成的图片样本，没有读取或改写个人浏览器资料。

## 已修复的问题

| 范围 | 复现的问题 | 处理 |
| --- | --- | --- |
| 搜索 | 重置后旧的延迟搜索重新出现；中文输入法组词期间提前执行搜索 | 统一取消／提交搜索任务，等待输入法完成后检索 |
| 收藏 | 整组和单图收藏按钮的图标与实际操作不一致 | 两种开关独立显示，用文字说明继承关系 |
| 大图导航 | 在收藏视图取消当前项后，导航变成 0/0 或跳项 | 大图使用打开时的姿势列表，关闭后刷新结果 |
| 批量选择 | 视角筛选后勾选整组会包含隐藏图片；对照模式无法开始勾选 | 全模式统一选择组内命中项，支持半选状态和对照勾选 |
| 资料保存 | 集合超过 100 个后重新读取时静默截断；第二标签页覆盖新收藏 | 保留有效集合，超限导入明确拒绝；按增删合并最新记录并同步标签页 |
| 键盘与焦点 | 关闭大图焦点落到已移除节点；更新侧栏丢焦点；空格拦截按钮操作 | 按稳定 ID 恢复焦点，复用导航节点，保留按钮原生操作 |
| 图片与提示 | 较矮窗口无法到达原尺寸；拖动过远；提示被原生对话框挡住 | 依据实际尺寸计算缩放和拖动范围，提示使用顶层浮层 |
| 原图拖出 | 大图禁用了原生拖拽，平移又捕获鼠标；自动化拦截拖放一度误判原生文件能力 | 未放大时保留浏览器原生文件，放大后 Alt 拖出；移除预读缓存和目录选择，用真实鼠标投递验证原图字节 |
| 读取反馈 | 悬停切换图片后，辅助标签仍是旧视角 | 同步更新图片 alt 与卡片标签 |
| 对话框 | 输入集合名按 Enter 触发取消；复用帮助与导入确认依赖关闭事件顺序 | 显式处理确定和取消，等待旧弹窗关闭，再进入资料确认 |
| 设置恢复 | 损坏的数字设置对象可能使初始化抛异常 | 仅接受有限数字，其余恢复默认值 |
| 压缩 | 重建失败虽回退映射，却已覆盖当前页面使用的 WebP | 衍生图按内容摘要命名，失败时保留旧页面、旧映射和旧图片 |
| 构建 | 在线构建缺图未立即失败 | 输出前验证同源图片，失败保留先前页面 |
| 发布 | 重复打包留下额外文件；非图片路径可能被带入发布目录 | 校验图片目录和编译清单，在新临时快照中准备后替换输出 |
| 补齐下载 | 仅凭文件头跳过的截断图片无法自动补齐 | 验证 PNG 块与 CRC、JPEG 结尾，再决定是否跳过 |
| 发布顺序 | 页面发布和功能检查并行，检查失败也可能已上线 | 合并工作流，只有 main 的检查成功后才发布该版本 |

## 验证方式

- `tests/test_gallery.py`：主要流程、离线打开、收藏与集合、备份与导出、多个视口、压缩安全性。
- `tests/test_review.py`：组合操作、多标签、输入法、键盘、资料边界和 Chromium 原生触控模拟。
- `tests/test_tool_review.py`：5 个生成样本测试，覆盖压缩失败、缺图、重复发布、非法路径和截断补齐。
- `tests/test_publish.py`：按仓库 URL 前缀提供发布目录，通过 HTTP 验证图片路径；用 Chromium 原生鼠标输入向接收区拖入实际文件，验证 900×1200 尺寸及与原图一致的 SHA256。
- `scripts/verify.py --decode`：2878 个图片引用逐张解码和尺寸检查。
- GitHub Actions 在 Ubuntu 上执行 Chromium 回归，成功后才启用发布任务；失败时保留截图。

## 验证范围

本机验证使用 Windows Edge 的隔离实例；窄屏、横屏和触控属于浏览器模拟。
这不等同于苹果 Safari 或 Android 真机测试，真实设备的系统手势与文件下载体验仍可继续验证。
浏览器入口与设备之间的本地记录独立，资料迁移仍需导出／导入。

## 界面精简

压缩标题区域，改用明确的“全部姿势／我的收藏／最近浏览”标题；提升辅助文字对比度和字号，帮助入口直接显示文字。
删除拖拽预读、文件缓存和目录选择模块，仅保留一行操作提示和原图下载。窄屏卡片省去过小的视角文字，视角仍可从当前图片标签与预览中查看。
